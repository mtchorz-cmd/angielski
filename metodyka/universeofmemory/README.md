# Metodyka: The Universe of Memory (Bartek Czekała)

Baza wiedzy z 67 artykułów z kategorii „Języki obce” (30) i „Nauka” (37) na https://universeofmemory.pl, przeczytanych w całości 2026-10-14.

- `ZASADY-DYDAKTYKI.md` — synteza: jak uczą się dorośli, pojemność pamięci, powtarzanie, słownictwo, gramatyka funkcjonalna, mówienie i korekta, słuchanie, motywacja, struktura kursu. Z sekcją krytyczną (czego nie brać bezkrytycznie) i checklistą do lekcji.
- `STYL-PISANIA.md` — analiza stylu polskiego autora i wzorzec do artykułów o nauce języków (bez kopiowania jego fraz, bez wulgaryzmów).
- `notatki-z-artykulow/` — surowe notatki per artykuł (teza, mechanizmy, liczby, krytyka, zastosowanie w kursach). Własne sformułowania, nie kopie tekstów. `lista-artykulow.md` to adresy URL.

Tekst oryginalnych artykułów NIE jest przechowywany w repo (prawa autorskie); wracaj do źródła po szczegóły i liczby.

Uwaga: liczby i badania podane są tak, jak je podaje autor. Dla materiałów dla uczniów sprawdź źródło pierwotne (patrz sekcja 10 w `ZASADY-DYDAKTYKI.md`).
